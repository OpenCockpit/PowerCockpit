# PowerCockpit (POC)
## Features
POC completes ongonging recordings and long running jobs like file operations or file downloads in standby mode before powering off.

## Limitations
- Tested on OpenViX and OpenATV with DM900.

## Installation
The plugin will be installed as a dependency, no explicit installation required.
